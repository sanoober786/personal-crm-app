# 📋 Mini Personal CRM

Built with **Python** and **Streamlit**, it is a simple, clean **Personal Client Relationship Manager (CRM)**.

This helps you to stay organized and manage your relationships better by enabling you to easily add, view, edit, and delete your client information.

---

## ✨ Features

- Add New Clients (Name, Email, Phone, Notes, Tag)
- View All Clients (expandable list with edit and delete options)
- Edit and Update Client Information
- Delete Clients
- Data saved locally as a **JSON file**
- Clean, responsive UI created using Streamlit
- Light and easy to deploy 

---

## 🚀 Technologies Used

- Python 3
- Streamlit
- Data storage in JSON
- UUID for unique client IDs

---

## 📦 How to Run


1. Install the required packages:

   pip install streamlit

2. Run the app:

   streamlit run mini_crm.py
